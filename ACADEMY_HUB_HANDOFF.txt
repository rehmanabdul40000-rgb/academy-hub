Current status
--------------
This is the stable LOCAL-STORAGE version of Academy Hub.

The experimental Supabase / PostgreSQL / scalable database / multi-user migration has been removed from the active project.

IMPORTANT:
- Do not re-add Supabase/scalable database code unless the owner explicitly asks for a future database migration.
- The application currently stores students, payments, settings, users/permissions, deleted records and workspace preferences in browser localStorage.
- Localhost and Vercel do NOT share data in this architecture. Each browser/device has its own localStorage.
- This is intentional for the current stable version.

Environment variables
---------------------
The current stable localStorage architecture does not require Supabase variables.

Do NOT add:
- VITE_SUPABASE_URL
- VITE_SUPABASE_PUBLISHABLE_KEY
- SUPABASE_URL
- SUPABASE_SERVICE_ROLE_KEY

unless the owner explicitly starts a new database migration project.

If initial admin provisioning uses:
  VITE_DEFAULT_ADMIN_PASSWORD

then configure that variable in Vercel Project Settings -> Environment Variables and redeploy after changing it.

Data warning
------------
Because the stable version uses browser localStorage:
- Localhost data stays in that browser/profile.
- Vercel data stays in the browser/profile used on the live site.
- A second computer does not automatically see the first computer's students.
- Vercel does not turn localStorage into a shared database.
- This limitation is intentional in the current stable release.
